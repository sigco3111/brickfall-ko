# 브릭폴 (Brickfall) 한국어판

**[▶ 지금 플레이 (GitHub Pages)](https://sigco3111.github.io/brickfall-ko/)** · [원작 Patch 페이지](https://patch.gg/games/blendi/brickfall) · [English README](README.en.md)

> Patch의 1인칭 복셀 철거 게임 **Brickfall**의 한국어 번역판입니다. Patch의 오픈 소스 저장소(코드 MIT)를 바탕으로 한 별도 한글화 미러이며, GitHub fork가 아니라 원작과 무관하게 독립 운영됩니다.

## 게임 소개

계약 하나가 작은 부지 하나와 제한 시간 하나입니다. 건물을 받치고 있는 것을 무너뜨리고, 층이 벽돌 하나하나씩 무너져 내리는 것을 지켜보세요. 모든 복셀은 그래픽 카드에서 시뮬레이션되는 실제 강체입니다. 벽은 이음새를 따라 갈라지고, 무너지는 구간은 닿는 쪽부터 층층이 부서지며, 잔해는 쌓인 자리에 그대로 남습니다.

재질마다 강도가 다릅니다. 슬레지는 석고와 목재를 뚫고 벽돌을 깎지만, 강철 보와 철근 콘크리트는 장약 없이는 버팁니다. 받치는 것이 사라진 바닥은 무너지고, 무너지기 전에는 강철이 삐걱거리고 먼지가 떨어지며 하중 게이지가 100%까지 차오릅니다. 프로판 탱크를 쏘면 화염구가 거리를 밝히고 벽을 까맣게 그을리며 다음 탱크를 연쇄 폭발시키고, 가스 배관을 뚫으면 불이 배관을 따라 연쇄 폭발합니다. 목재·플라스틱·생울타리는 불이 붙어 타들어가고, 연기는 길을 잃을 만큼 짙습니다.

연쇄를 쌓아 콤보를 최대 x5까지 올리고, 가장 큰 붕괴는 틸트시프트 카메라의 슬로모션 리플레이로 기록되어 결과 화면에서 다시 볼 수 있습니다. 타격은 무엇을 때렸는지, 어디서 때렸는지에 따라 벽돌·콘크리트·석고·목재·강철 각각의 파편 소리로 공간에 울립니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| **러시** | 계약당 90초, 모든 도구 사용. 혼돈을 점수로 바꾸는 속공 모드 |
| **블로우다운** | 시간 제한 없음. 장약과 절단 장약에 지연을 설계해 한 번에 기폭. 건물이 제 자리에 깔끔하게 무너지고 주변 피해가 적을수록 고득점 |
| **샐비지** | 강도질 계획 모드. 시간 제한 없이 침입로를 뚫고 벽에 배선하고 판자를 놓으며 계획을 세웁니다(F5 퀵세이브, F9 불러오기). 첫 전리품을 가져가는 순간 60초 경보가 울리고, 나머지를 챙겨 헬기가 오기 전에 도주 트럭에 도달하세요 |
| **샌드박스** | 모든 부지에서 모든 도구 무제한. B로 탱크·가스통·자동차·상자·연료 탱커 소환, T로 시간대 변경 |

## 부지 11곳

| 부지 | 목표 |

| 교회 | 아랫단이 보강된 돌 첨탑을 예배당을 피해 링 안으로 쓰러뜨리기 |

## 도구 9종

슬레지(누르고 있다가 휘두르기), 캐논(벽을 관통하는 무거운 포환), 장약, 절단 장약(강철까지 끊는 일자 절단), 잭해머, 로켓, 파이프 폭탄(튕기다가 폭발), 판자(최대 5m 다리·경사로), 케이블.

모드에서 얻은 별이 누적되면 후반 도구와 부지가 열립니다: 잭해머 3개, 절단 장약 6개, 파이프 폭탄 9개, 로켓 12개 / 모퉁이 타워 4개, 교회 22개. 샌드박스는 처음부터 전부 사용할 수 있습니다.

## 조작법

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 (클릭으로 캡처, Esc 일시 정지) |
| 좌클릭 | 도구 사용 |
| 1–9 / 휠 | 도구 전환 |
| 우클릭 또는 Q | 장약 기폭 |
| R | 장약 지연 설정 |
| L | 하중 보기 |
| Space / Shift / C | 점프 / 달리기 / 앉기 |

| F5 / F9 (샐비지) | 퀵세이브 / 불러오기 |

## 기술 스택

- **언어/엔진**: TypeScript + [three.js](https://threejs.org) (WebGPU 렌더러)
- **물리**: [three-avbd](https://github.com/sbobyn/three-avbd) — GPU 강체 솔버 (AVBD, SIGGRAPH 2025). 원작 엔진은 Steven Bobyn의 [three-voxel-destruction](https://github.com/sbobyn/three-voxel-destruction)이 복셀 물리·파괴·구조·렌더링·먼지를 담당
- **빌드**: Vite → 정적 파일(dist/)
- **모델 없음**: 부지, 건물, 소품, 도구, 트럭 모두 코드 속 복셀과 박스로 생성
- **아트**: Poly Haven 텍스처·하늘(CC0), 폰트(OFL), 생성 음악

## 실행 방법

Node 22 이상, pnpm 10, WebGPU 지원 브라우저(Chrome/Edge 113+, Safari 26, Windows의 Firefox 141+)가 필요합니다.

```sh
pnpm install
pnpm dev          # http://127.0.0.1:5320
pnpm build        # dist/ 생성 (정적 배포용)
pnpm typecheck    # 타입 검사
pnpm test         # 단위 테스트
```

## 검증 상태

- `pnpm typecheck`(tsc) 통과, `pnpm test` 9/9 통과, `pnpm build` 통과
- GitHub Pages 배포본을 직접 열어 한글 WebGPU 안내 화면과 한글 폰트 적용을 확인 (위 스크린샷)
- 실제 플레이 화면은 WebGPU가 필요하여 빌드·캡처 환경에서는 확인하지 못했습니다. PC Chrome/Edge에서 플레이해 보시고 이상이 있으면 알려 주세요.
